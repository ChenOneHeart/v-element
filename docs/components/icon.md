# Icon 图标

常规的图标，使用fontawesome进行二次封装的图标组件，通过`icon`属性可以传入图标参数，支持fontawesome所有参数。
（fontawesome的详细用法参阅https://docs.fontawesome.com/web/use-with/vue）。
