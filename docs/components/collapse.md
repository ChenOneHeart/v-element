# Collapse 折叠面板

折叠面板包含 `基础用法`, `手风琴`，通过折叠面板可以收纳内容区域，作为常规的数据展示组件。

## 基础用法

可同时展开或折叠多个面板，面板之间互不影响

<preview path="../demo/Collapse/Basic.vue" title="基础用法" description="Collapse 基础用法"></preview>

## 手风琴
带有手风琴效果的折叠面板，每次只能展开一个面板，展开面板时其他面板会关闭，可以通过`accordion`属性设置是否开启。
